# Registro de uso de IA

## Objetivo
Documentar el uso de IA como apoyo para estructurar una calculadora académica con datos sintéticos.

## Prompt inicial
“Con los datos sintéticos 110, 60, 20 y 10, desarrolla una calculadora en HTML, CSS y JavaScript que calcule proporción de espera automática, intervalo Wald aproximado del 95 %, tamaño de muestra para error absoluto 0.05, alturas a 50 mm bajo el codo y momentos M=F×d. Incluye validaciones, unidades, supuestos y limitaciones. No inventes mediciones reales ni afirmes pruebas ejecutadas.”

## Prompts de corrección
1. “Verifica manualmente las fórmulas y resultados esperados con los datos de prueba.”
2. “Agrega validación para conteos negativos, decimales y total cero.”
3. “Aclara que las dimensiones antropométricas son ficticias y que el momento no es un límite de seguridad.”
4. “Genera pruebas públicas con resultados esperados y espacio para registrar la ejecución real.”

## Registro para completar

|---|---|---|---|---|

## Limitaciones
La IA puede producir errores aritméticos, supuestos inadecuados o defectos de código. El equipo debe verificar fórmulas con cálculo manual, revisar el código y ejecutar las pruebas. La IA no sustituye observaciones reales, evaluación ergonómica profesional ni mediciones ambientales.
